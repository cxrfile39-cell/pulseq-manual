Pulseq 把序列寫成一個檔案

Pulseq 是開源、跨廠商的脈衝序列框架：你用 MATLAB/Octave 或 Python 描述序列，匯出成 .seq 文字檔，再由掃描儀上的直譯器執行。不必寫 IDEA 或 EPIC，同一個檔案也能丟進模擬器先看結果。框架以 MIT 授權開源，原始論文為 Layton et al., MRM 2017;77(4):1544–1552。

它的好處是快（改參數重跑腳本就能上機）、透明（每個 RF、梯度、ADC 都寫在檔案裡）、可分享（附在論文或 GitHub 就能重現）。

工作流程

  1. 設計：MATLAB 或 Python 腳本
  2. 檢查：checkTiming、plot、k-space、PNS；不通過就回到 1
  3. 匯出 .seq
  4. 模擬（選用）：MRzero、KomaMRI、JEMRIS
  5. 上機：廠商直譯器執行
  6. 重建：從原始資料 reshape、iFFT 或 NUFFT

學完能做什麼

  • 用 MATLAB 或 Python 從零寫出 FID、2D GRE 序列，並看懂官方範例（SE、TSE、EPI、螺旋）再改成自己要的版本
  • 自己算 TE/TR 延遲、梯度面積和 k-space，知道參數為什麼「設不下去」
  • 上機前用時序檢查、波形圖、k-space、PNS 與模擬確認序列沒問題
  • 看懂 .seq 檔；取得直譯器後能在掃描儀執行，並從原始資料重建影像
  • 把序列以 .seq 檔分享，讓別人重現你的實驗

本手冊是入門：學完約是「能獨立做出並驗證基本序列」的程度。開發新技術還需要更深的 MR 物理、RF 脈衝設計與重建知識。

核心概念：系統限制、事件、區塊

序列是一串依序執行的區塊（block），每個區塊裡放同時開始的事件（event），所有事件依你宣告的系統限制來計算。上方實驗室圖中的虛線，就是五個區塊的邊界。

事件

事件MATLAB用途

區塊規則

  • seq.addBlock(a, b, …) 裡的事件同時開始；要晚一點就設事件的 delay。
  • 區塊長度 = 最長的事件，用 mr.calcDuration 計算。
  • 每軸一個梯度、一個 RF、一個 ADC；區塊不會重疊。
  • 區塊結尾梯度不為零時，下一個區塊必須從同一值接上。

單位：Pulseq 內部用 Hz

梯度 Hz/m、slew Hz/m/s、RF 振幅 Hz，都已乘上 γ = 42.576 MHz/T。好處是梯度對時間的積分直接就是 k（1/m），且 Δk = 1/FOV。

單位換算器

第一個序列：FID

一個 90° 硬脈衝、一段 ADC、一段等待。沒有梯度，最適合拿來確認「安裝 → 匯出 → 上機」整條路是通的。注意 calcDuration(rf) 已包含死時間與 ringdown；時間用秒、角度用弧度。

練習：翻轉角改成 30°、TR 改成 500 ms，重新匯出並用 seq.plot() 確認。然後回到上方實驗室，試著把 TE 調到低於最短 TE，看會出現什麼錯誤。

安全事項

  
    
   
  • 你對序列安全負責。能寫出廠商介面不允許的波形，不代表它安全。

重建：資料順序就是你的迴圈順序

 
原始資料是每個 ADC 依執行順序排成一列；照同樣順序 reshape 即可。序列一複雜（多層、多回波、平均），就加上標籤（label），寫入計數器 LIN、PAR、SLC、ECO、AVG、REP，重建時不必猜。非笛卡兒軌跡用 calculateKspacePP 取得座標，交給 NUFFT（BART、SigPy、MIRT）。

 






 
除錯：搜尋你看到的症狀

 
初學者的錯誤幾乎都來自三件事：時間沒對齊柵格、延遲算成負值、單位搞混。
